01.

关于我

你好！我是李泽玺，上海交通大学电子科学与工程专业博士研究生，研究方向是新兴计算范式（随机计算 Stochastic Computing 和近似计算 Approximate Computing）——用随机比特流实现算术与逻辑运算，并在其上设计高效的电路与架构，最终服务于神经网络加速器。

我的日常在 Verilog、Rust 和 Python 之间切换：写 RTL、开发设计与仿真工具、做设计空间探索——用合适的工具解决合适的问题。

本科在密西根学院度过，担任《微处理器系统设计》《电子电路》《半导体器件导论》三门课的助教，也完成了第一个研究项目——用 Java 和 ESP32 折腾物联网开发。🧋
